# Todo Application

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL

## Features
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Data stored in PostgreSQL

## Project Structure

Project2/
│
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
│
└── backend/
    ├── server.js
    ├── db.js
    ├── package.json
    └── node_modules/

## How to Run

1. Start PostgreSQL.
2. Open the `backend` folder.
3. Run:

```bash
node server.js
```

4. Open the `frontend` folder using Live Server.
